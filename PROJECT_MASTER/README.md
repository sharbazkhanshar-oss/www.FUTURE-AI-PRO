# Future AI Pro — Master Project Reference

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Add your API keys to .env
# (see PROJECT_MASTER/03-PUBLISH-GUIDE.md for details)

# 3. Run the server
npm start

# 4. Open browser
# http://localhost:3000
```
